# Disalvi en Jekyll

    bundle install
    bundle exec jekyll serve

Abre http://localhost:4000

## Imagen del inicio

Guarda la foto de fondo como `assets/img/hero.jpg` (unos 2000 px de ancho, menos de 400 KB).
Mientras no exista, el inicio se ve con fondo azul oscuro.

## Imágenes de los servicios

Guarda una foto por servicio en `assets/img/servicios/` (unos 1200 × 800 px, menos de 250 KB cada una):
espejos.jpg, domos.jpg, barandales.jpg, canceles-de-cristal-templado.jpg,
canceles-de-bano.jpg, ventanas.jpg, cubiertas.jpg.
Sin foto, el recuadro se ve azul oscuro con el título.
